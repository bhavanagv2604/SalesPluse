# SalesPulse 📊

An E-commerce Sales ETL and Analytics Dashboard built with Python.

## Features
- Sales data cleaning using Pandas
- ETL pipeline with duplicate and missing-value removal
- Revenue calculation
- Interactive sales dashboard
- Product revenue analysis

## Technologies
- Python
- Pandas
- Streamlit
- Plotly

## Run locally
Install the requirements:

pip install -r requirements.txt

Launch the dashboard:

streamlit run dashboard.py
